How the Xiaomi S200 connects

The Rust app finds the scale over Bluetooth Low Energy and lists its GATT services.

cargo run

Run from the project folder in Windows Terminal, then step on the scale to wake it.

Scale missingWake it while the app is listening.

Bluetooth unavailableTurn Bluetooth on and run from Windows Terminal.

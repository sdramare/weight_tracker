How the Xiaomi S200 connects

The desktop and terminal apps share a Rust library for finding the S200 over Bluetooth Low Energy.

cargo run -p blt_unlock_gui

Open the desktop app and see scales as they appear.

cargo run

Connect to the first available scale and list its GATT services.

Run either command from the project folder, then step on the scale to wake it.

Inspect scale setup

cargo run -- --check-setup

Wake the scale, then sign in once. See a result for each Bluetooth and Xiaomi account check.

cargo run -- --setup-info --seconds 30

Wake the scale during the scan. No bind key is required.

Product IDIdentifies the S200 variant.

AuthenticationShows the setup protocol advertised in MiBeacon v5.

RegistrationShows whether the scale is registered or requesting setup.

cargo run -- --setup-test-cert --seconds 30

Exchange keys with an unregistered S200 ms113, then send an encrypted test identity and certificate.

cargo run -- --xiaomi-sign-in

Verify Xiaomi smart-home account authorization using a one-time browser link.

cargo run -- --xiaomi-check-cloud

Sign in and check whether Xiaomi’s Europe API accepts a signed, read-only account request.

If the connection fails

Scale missingWake it while the app is listening.

Scale unreachableClose Xiaomi Home if it is connected, then wake the scale again.

Bluetooth unavailableTurn Bluetooth on and run from Windows Terminal.
